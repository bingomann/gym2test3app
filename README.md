# Gym Track Minimal App

Hier sind alle Dateien für deine minimalistische Gym-App.

## Setup auf GitHub Pages:
1. Erstelle ein neues Repository auf GitHub (z.B. `gym-app`).
2. Lade alle Dateien aus dieser ZIP (`index.html`, `manifest.json`, `README.md`) direkt in das Repository hoch.
3. Gehe in den GitHub-Repository-Einstellungen zu **Settings -> Pages**.
4. Wähle unter **Build and deployment -> Branch** den Branch `main` (oder `master`) aus und klicke auf **Save**.
5. Nach 1-2 Minuten ist deine App unter `https://<dein-github-name>.github.io/gym-app/` erreichbar!

## Auf dem Android-Handy installieren (PWA):
1. Öffne den Link in Chrome auf deinem Smartphone.
2. Tippe oben rechts auf die 3 Punkte.
3. Wähle **"Zum Startbildschirm hinzufügen"** (oder "App installieren").
4. Fertig! Die App läuft als echte Android-App offline und speichert deine Trainingsdaten sicher in `IndexedDB`.
